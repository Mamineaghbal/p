# 🧮 Function Analysis — Mathemagical Engine

A web-based tool to define, analyze, and visualize mathematical functions, sequences, and series using Flask and SymPy.

## ✅ Features

- Input & auto-detection of functions, sequences, series, piecewise
- Symbolic & numerical analysis (domain, derivatives, limits, integrals, variation, concavity, injectivity, inverse, Taylor series)
- Interactive 2D plotting with Plotly.js
- Educational mode with step-by-step LaTeX-rendered derivations
- Save analyses to SQLite database
